# henotes-site — henotes.lupa.kr

헤노테스(Henotes) 찬양팀 실황 멀티트랙 모니터의 **소개 랜딩 페이지**. 정적 HTML 한 장.

- 앱 본체: https://github.com/paeyoungpark-web/worship_henotes → https://worship-henotes.pages.dev/
- 이 페이지: GitHub Pages + `CNAME`(henotes.lupa.kr). Cloudflare DNS에 `henotes CNAME paeyoungpark-web.github.io` 추가하면 연결됨.
- 디자인 규칙은 앱 리포의 `CLAUDE.md`를 따른다 (다크 뉴트럴 + 오렌지 단일 액센트, Pretendard / JetBrains Mono, Lucide 인라인 SVG, 이모지 아이콘 금지).
- 앱 URL을 바꾸면 `index.html`에서 `worship-henotes.pages.dev`를 일괄 치환.
